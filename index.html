How to Run & Deploy This Application

1

Get Your Free ElevenLabs API Key

Go to elevenlabs.io, sign up or log in, click your profile icon at bottom-left, and select API Keys. Copy your API key.

2

Configure Locally (Option A)

Create a file named .env in this project folder and write:

ELEVENLABS_API_KEY=your_copied_api_key_here

Then install Netlify CLI (npm install -g netlify-cli) and run netlify dev. It will launch on http://localhost:8888.

3

Deploy to Netlify (Option B - Recommended)

  1. Push your project code to a GitHub repository.
  2. Log in to Netlify and click "Add new site" → "Import an existing project".
  3. Select your GitHub repository. Netlify detects netlify.toml automatically.
  4. Under Environment Variables, add ELEVENLABS_API_KEY with your key value.
  5. Click Deploy site. Your website goes live with a secure HTTPS URL!
🔒 Security Tip: Never paste your API key directly into script.js or index.html. Because this app uses Netlify functions, only your server can see the key!
